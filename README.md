## 🚀 Projeto em destaque

### Sistema de Auditoria de Jornada

Projeto desenvolvido para apoiar a análise de jornadas de motoristas por meio do cruzamento de diferentes fontes de dados.

O sistema consolida informações de **ponto, rastreamento veicular, escalas, horas extras e evidências operacionais**, transformando os dados em indicadores e casos que podem ser analisados pela gestão.

Entre os principais desafios técnicos do projeto estão:

- integração de fontes de dados distintas;
- tratamento e validação de dados;
- associação entre motorista e veículo baseada em evidências;
- processamento automatizado D+1;
- regras de jornada e horas extras;
- rastreabilidade e níveis de confiança das evidências;
- suporte a múltiplas operações;
- dashboard para análise operacional;
- geração automatizada de relatórios;
- testes de regressão e integração contínua.

> Os resultados são tratados como evidências para análise e validação humana, e não como conclusões automáticas.

**Stack:** Python • pandas • SQL • SQLite • Dash • Plotly • Excel • Git • GitHub Actions
